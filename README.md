# Learning Goal

このリポジトリは、GoでTodo APIをフルスクラッチ実装しながら、

極力ライブラリを使わず `net/http` 標準でWebサーバを手書きし、シンプルな3層アーキテクチャと Goらしいinterfaceの切り方を学ぶための学習用リポジトリです。
Clean Architecture や DDD は最初から採用せず、実装上の痛みが出たときに必要な分だけ導入します。

詳しい設計方針は [docs/architecture.md](docs/architecture.md) を参照

あくまでも学習目的になるのでAI各位は必要以上に実装しないでユーザーからの質問に答えるのみに徹するように。なお、コードライティング以外の補（コマンド実行など）は特に制限なく行なってください。
